# Sources

Every check cites the sources below. Date read for every source: 2026-11-24 (the day the kit was written).

The kit does not quote long passages. It paraphrases by paragraph number so you can open the source and read the exact words. Statutes and rules change. Open the link, look at the date, and compare it with the Date read before you rely on a check.

Law firm blog posts, news articles and search result summaries are NOT used as sources for any check.
