# Changelog

## v1.0.0 (2026-11-24)

First release.

- 33 numbered checks with a source, the date it was read, how to fix it, a paste in prompt and a Pass or Needs work field.
- Quick start, full audit and report prompts.
- Templates: consent proof log, lead source register, stop request log, results sheet (sample rows are made up and labelled SAMPLE).
- Docs: start here, how to run with Claude Code, Codex or ChatGPT, honest limits, sources with dates, glossary.
- Claude Code skill `dial-warrant`.
- Tools: `validate_kit.py` (counts and checks the kit) and `rank_fixes.py` (ranked fix list from a results sheet). Offline tests.
- Known gaps: sources that could not be opened are listed in `docs/03-SOURCES.md`. Texas and Utah are not covered. The FCC amendment published October 26, 2026 (91 FR 67219) was not read.
